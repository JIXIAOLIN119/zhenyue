We support three installation options. For most administrators, **Docker Compose** is the fastest and easiest way to deploy ZhenYue.

---

## Option 1: Docker Compose (Recommended)

Docker Compose automatically configures and spins up all required services (the web application, a database, and local storage).

1.  **Download the Configuration**:
    ```bash
    curl -o docker-compose.yaml https://raw.githubusercontent.com/zhenyueOne/zhenyue/main/docker-compose/local/docker-compose.yaml
    ```
2.  **Start the Services**:
    ```bash
    docker compose up -d
    ```
3.  **Access the Dashboard**:
    Open your browser and navigate to **`http://localhost:3000`** to access the ZhenYue Web UI.

### Production Deployments (Temporal)

If you are deploying ZhenYue for a production team with high-volume video uploads, we recommend setting up a distributed deployment using **Temporal** and an S3-compatible storage backend. This offloads resource-heavy video transcoding and AI agents to separate, dedicated worker nodes to keep your main dashboard fast and responsive. For setup instructions, see the [Deploy with Temporal](/configuration/temporal) guide.

## Option 2: Install via NPM

You can run ZhenYue as a global service using the Node Package Manager (NPM).

### System Prerequisites

To handle media processing and security isolation, the host machine must have the following system utilities installed:

- **FFmpeg & FFprobe**: Required for video transcoding and metadata extraction.
  - _macOS_: `brew install ffmpeg`
  - _Linux (Ubuntu/Debian)_: `sudo apt-get install ffmpeg`
- **Agent Sandbox Utilities**: Used to run custom automation scripts securely.
  - _macOS_: `brew install ripgrep`
  - _Linux (Ubuntu/Debian)_: `sudo apt-get install bubblewrap socat ripgrep`

### Step-by-Step Setup

1.  **Start a Database**:
    ZhenYue requires a PostgreSQL database with the `pgvector` extension. Start a database container:
    ```bash
    docker run --name zhenyue_postgres \
      -e POSTGRES_USER=zhenyue \
      -e POSTGRES_PASSWORD=zhenyue_password \
      -e POSTGRES_DB=zhenyue_db \
      -p 5432:5432 \
      -d pgvector/pgvector:pg18
    ```
2.  **Install ZhenYue**:
    ```bash
    npm install -g @zhenyue-one/zhenyue
    ```
3.  **Configure Environment Variables**:
    Create a new directory, navigate into it, and create a `.env` file:

    ```bash
    mkdir zhenyue && cd zhenyue
    ```

    Create a `.env` file with the following variables:

    ```env
    DATABASE_URL=postgresql://zhenyue:zhenyue_password@localhost:5432/zhenyue_db?schema=public
    BETTER_AUTH_SECRET=your-random-32-character-secret-key
    STORAGE_BACKEND=local
    AWS_ENDPOINT_URL_S3=http://localhost:3000
    ```

    > [!TIP]
    > `AWS_ENDPOINT_URL_S3` must include the scheme and port (e.g. `http://localhost:3000`) where ZhenYue is publicly accessible. This URL is used directly by client browsers for file uploads.

4.  **Start ZhenYue**:

    > [!IMPORTANT]
    > **For Bun Users:** Since the published package binaries contain a `#!/usr/bin/env node` shebang, running `zhenyue` directly will execute under Node.js. If you installed using Bun and want to run it under the Bun runtime, prefix the command with `bun run --bun` (e.g., `bun run --bun zhenyue`).

    ```bash
    zhenyue
    ```

    Open your browser to `http://localhost:3000`.

## Option 3: Run from Source (For Developers)

If you wish to run ZhenYue locally to customize the platform or contribute:

1.  **Clone the Repository**:
    ```bash
    git clone https://github.com/shumaiOne/shumai.git
    cd zhenyue
    ```
2.  **Install Dependencies**:
    ```bash
    bun install
    ```
3.  **Start a Database**:
    Launch a local database container (as described in the NPM section above).
4.  **Run Migrations**:
    Set up your `.env` file at the root, then apply database migrations:
    ```bash
    bun run db:migrate
    ```
5.  **Start the Dev Server**:
    ```bash
    bun run dev
    ```
    This spins up the web server on port `3000` with hot-reloading active.
